# Ирина против комаров

Браузерная роглайт-аркада про бессонную ночь. Ирочка ложится спать, а комары не дают:
только она засыпает, новое «бзз» будит её. Игрок — руки Ирины.

**Играть:** https://allgrit.github.io/irina-vs-komaru/

## Что внутри

- Ночь из семи часов, каждый час — волна комаров по кривой сложности.
- Семь видов комаров: Пискун, Стрелок, Тихоня, Бомбардир, Мелочь, Хамелеон и босс Матка.
- Шесть инструментов ловли с разной механикой ввода: ладонь, хлопок с зарядкой, мухобойка
  жестом, электроракетка с батареей, пылесос, спрей. Плюс лампа как тактический тумблер.
- Перк на каждый час (24 штуки, три редкости), лавка между ночами, уровни ночей.
- Задания с прогрессом между забегами, локальная таблица рекордов, ежедневный вызов
  с общим сидом и коды результатов для обмена с друзьями.
- Вся графика процедурная на Canvas 2D, звук синтезируется Web Audio. Внешних файлов нет.

```

git config core.hooksPath .githooks   # pre-commit: check + тесты
```
